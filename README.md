## 在线可用

- 4模块、36学习条目（含骨群、组成部分和标志），13张教材图。
- 96道自编题；日常练习60题，独立前测、后测、保持测验各12题。
- 错题复习、笔记、本机记录、教师导入与人工复核。
- AI伴学初答草稿、历史记录、导入导出与跨地址迁移。

GitHub Pages托管静态网页。在线版支持每位访问者填写自己的DeepSeek或千问API密钥，由浏览器直接调用固定的官方接口，无需另开本地服务。密钥只保存在当前页面内存，启用后清空输入框；刷新、离开或点击清除后需重新填写。不写入localStorage、sessionStorage、导出档案或GitHub。问题与所选教学图片会发给所选官方模型，调用消耗填写者自己的账号额度。没有密钥也能使用课程与练习。在线学习记录保存在访问者当前浏览器，未上传中央数据库。

## 在线启用个人密钥

打开页面顶部“填写自己的API密钥”，选择DeepSeek或千问及地域/模型，粘贴有效API Key，点击“启用本次密钥”。启用本身不调用模型；可点击“检测文字连通”进行真实请求，再进入AI伴学课堂或教学问答。刷新会清除密钥；旧伴学会话需要重新获得追问。网络或跨域受限时可使用下述本地方式。

## 启用本地真实AI

下载仓库ZIP并解压，安装Node.js 20+。Windows双击 `启用AI.cmd`，选择DeepSeek或千问，在本机命令窗口隐藏输入有效API Key；使用 `http://127.0.0.1:8790/`。仅预览本地网站也可执行 `node server.mjs`。

初答与依据 → AI引用原文追问 → 回应与修正 → AI比较前后解释 → 程序匹配迁移题 → 教师复核。密钥仅在服务进程环境中使用，不要提交到仓库。
